Start with the job, not the catalog.

In Your Niche, it is easy to collect tabs and still not know what “good” looks like. This stub walks a reader through a **neutral evaluation** so later buying guides have something to hang on.

## Write the job in one sentence

Example: “I need a Your Niche setup that a beginner can run weekly without a specialist.” If you cannot write that sentence, you are not ready to compare SKUs. See the [research checklist](/guides/getting-started/research-checklist/) before you go further.

## Score what you can observe

Use a short rubric. Replace these rows when the niche is real:

| Criterion | Why it matters | How you will check it |
| --- | --- | --- |
| Fit for the job | Stops catalog browsing | Map features to the sentence above |
| Support & docs | Reduces dead-end Fridays | Read one official guide end to end |
| Exit cost | Avoids lock-in | Ask how data leaves the product |
| Total cost | Sticker price lies | Add accessories, plans, and time |
